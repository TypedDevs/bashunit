# {{ $frontmatter.title }}

<time>{{ $formatDate($frontmatter.date) }}</time>

Release 0.51.0 reduces the work surrounding each test while keeping Bash 3.0 as the compatibility floor. It also corrects coverage for multiline statements and several cases involving similar test names or cleanup after timeouts.

## Faster hooks and counting

Tests that define `set_up` or `tear_down` no longer create and remove extra output files for every hook. In a recorded macOS arm64, Bash 3.2 measurement, a test with hooks fell from 14.1 ms to 5.4 ms, about 2.6 times faster ([#1345](https://github.com/TypedDevs/bashunit/issues/1345)).

Source locations are resolved when needed instead of through a subshell for every sequential test. In another measurement on the same platform, a 500-test file fell from 2.75 seconds to 2.40 seconds ([#1346](https://github.com/TypedDevs/bashunit/issues/1346)).

The header count reuses information from the function scan for files it can count safely. Files with providers, heredocs, multiline strings or dynamic definitions retain the fallback that loads them. Across the repository's 241-file measurement, counting fell from 1.72 seconds to 1.51 seconds ([#1347](https://github.com/TypedDevs/bashunit/issues/1347)).

Parallel runs on shells without `EPOCHREALTIME` also avoid probing the clock once per test. The 500-test regression fixture now executes Perl twice instead of 502 times.

## More accurate coverage

Coverage counts each line of multiline arrays, quoted strings, heredocs and continued statements. Previously an array spread across several lines could look partially uncovered, and on Bash 3.x could look entirely uncovered. Hits on a parent statement no longer mark commands inside substitutions as covered ([#1338](https://github.com/TypedDevs/bashunit/issues/1338)).

## Test selection and cleanup fixes

`test_a` and `test_ab` are no longer mistaken for duplicate definitions. An `--exclude-filter` value containing a comma stays one test name; repeat the option to exclude several names. The environment setting `BASHUNIT_EXCLUDE_FILTER` keeps its comma-separated behavior.

Timed-out tests get a bounded opportunity to finish `tear_down`, with the watchdog waiting for the test body to exit rather than assuming a fixed short delay will always suffice. Parallel runs also stop replaying Bash's process-group warning as if it came from a test file ([#1344](https://github.com/TypedDevs/bashunit/issues/1344)).

Internally, helpers can select an optimized implementation for a newer Bash once at load time while retaining the Bash 3.0 fallback. This does not raise the minimum supported version.
