<time>{{ $formatDate($frontmatter.date) }}</time>

Release 0.45.0 adds ways to check symbolic links, invoke commands through boolean assertions, and keep multiple snapshots in one test. It also fixes cases where malformed inputs or missing commands could produce misleading results.

## Check the link itself

Most filesystem assertions follow a symbolic link to its target. The new `assert_is_symlink`, `assert_is_not_symlink`, and `assert_symlink_to` inspect the link itself, making them useful for scripts that maintain a current-release link ([#981](https://github.com/TypedDevs/bashunit/issues/981)).

```bash
function test_current_release_link() {
  assert_is_symlink "./current"
  assert_symlink_to "./releases/42" "./current"
}
```

## Pass arguments directly to boolean assertions

`assert_true` and `assert_false` now accept a command followed by its arguments. A single argument retains its previous meaning ([#994](https://github.com/TypedDevs/bashunit/issues/994)).

```bash
function test_release_directory() {
  assert_true test -d "./releases/42"
  assert_false test -d "./releases/missing"
}
```

Both assertions now fail when the command is unknown or not executable. A missing command is no longer accepted by `assert_false` as evidence that the intended condition was false; the failure message explains that the command could not run ([#982](https://github.com/TypedDevs/bashunit/issues/982)).

## Keep snapshots distinct and results reliable

Named snapshots let a test record more than one expected value. On a mismatch, bashunit shows the resolved snapshot path and the `--snapshot-update` hint. Absolute test paths now resolve snapshots correctly, and the fallback for snapshot placeholders checks the whole value when Perl is unavailable ([#986](https://github.com/TypedDevs/bashunit/issues/986), [#1002](https://github.com/TypedDevs/bashunit/issues/1002)).

Input checks are stricter too: core comparison assertions reject missing arguments, date assertions reject unparseable values, and `assert_json_equals` rejects invalid JSON. Parallel runs retain results from same-named test files in different directories.

Several existing checks avoid repeated processes, including literal snapshots, spy counters, case-insensitive containment, and common numeric-tolerance comparisons. The standalone build also omits source comments while preserving heredoc content and source markers. These changes keep the test-facing behavior intact while reducing work around it.
