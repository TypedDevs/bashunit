<time>{{ $formatDate($frontmatter.date) }}</time>

Release 0.49.0 distinguishes an intentionally empty test selection from an invalid path. It also adds tag discovery and fixes resource handling that could stop large suites from executing all their tests.

## Allow an empty selection deliberately

By default, selecting no tests remains a failure. `--pass-with-no-tests` makes that case exit successfully while still printing “No tests found”. This is useful for an empty CI shard or a changed-files run with no matching tests ([#1263](https://github.com/TypedDevs/bashunit/issues/1263)).

```bash
bashunit --changed origin/main --pass-with-no-tests tests/
```

A nonexistent path is still an error. An explicitly empty directory also no longer falls back to `BASHUNIT_DEFAULT_PATH`, so the runner cannot pass a different suite from the one you requested.

## Find the tags you can select

`--list-tags` prints the selected files' tags in sorted order, without duplicates, and runs no tests:

```bash
bashunit --list-tags tests/
bashunit --tag slow tests/
```

If a tag matches nothing, the runner now lists the tags it saw, or explains that no test carries one. That makes a spelling error easier to distinguish from an empty selection ([#1265](https://github.com/TypedDevs/bashunit/issues/1265)).

## Keep large suites complete

Sequential runs no longer leak a file descriptor per test file. The old leak could exhaust the limit, stop executing assertions and still exit successfully. A regression fixture with 120 files and a 120-descriptor limit previously ran only two assertions instead of 120 ([#1271](https://github.com/TypedDevs/bashunit/issues/1271)).

Per-test cleanup also stops scanning the entire shared temporary directory. The recorded 100-test fixture fell from 978 ms to 542 ms with 5,000 leftovers present. Use `bashunit::temp_file` and `bashunit::temp_dir` for automatic cleanup; files written there by hand are no longer removed for you ([#1269](https://github.com/TypedDevs/bashunit/issues/1269)).

Snapshot reporting and pruning now find snapshots left by deleted or renamed test files. They still leave snapshots belonging to existing files outside the current run alone. Review the listed paths before pruning: this release widens the set of orphaned snapshots it can remove ([#1194](https://github.com/TypedDevs/bashunit/issues/1194)).
