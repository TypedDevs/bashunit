# {{ $frontmatter.title }}

<time>{{ $formatDate($frontmatter.date) }}</time>

Release 0.43.0 adds branch coverage for loops and reduces the number of processes started by assertions and parallel workers. Existing assertions keep their behavior, so the process changes do not require rewriting tests.

## Find loops your tests never enter

Branch coverage now includes `while`, `until`, `for`, and `select`. Each loop body is represented as a single branch, covered when the loop runs at least once. A test that only exercises an empty input can therefore leave the loop body uncovered even when the surrounding function runs successfully ([#855](https://github.com/TypedDevs/bashunit/issues/855)).

```bash
bashunit tests/ --coverage --coverage-paths src/
```

For a function that processes a list, include both an empty-list case and a case with at least one item. The first checks what happens when the loop is skipped; the second reaches its body. The coverage report now makes the missing body case visible. It records whether the loop was entered, rather than reporting a separate branch for each iteration.

## Fewer processes for the same assertions

String assertions such as `assert_contains`, `assert_matches`, and the prefix and suffix checks no longer start a subshell to join their arguments. Array, date, duration, JSON, file, and folder assertions also resolve their failure labels without a command substitution. The labels and comparison behavior stay the same ([#844](https://github.com/TypedDevs/bashunit/issues/844)).

Parallel workers now name result files using an ordinal assigned by the suite, replacing a temporary-file creation and rename for every test. Data-provider tests also avoid the argument-sanitizing pipeline previously used for those names. Result aggregation is unchanged ([#851](https://github.com/TypedDevs/bashunit/issues/851)).

```bash
bashunit --parallel tests/
```

These changes reduce repeated process work as the number of assertions and tests grows, without introducing new options or changing how you invoke the suite.
