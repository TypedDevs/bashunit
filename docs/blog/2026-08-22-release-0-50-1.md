<time>{{ $formatDate($frontmatter.date) }}</time>

Release 0.50.1 focuses on cleanup. Hooks now release resources across setup failures, early stops, invalid annotations and interrupted runs, with the same ownership boundaries in sequential and parallel execution.

## File resources stay alive until their tests finish

Under `--parallel`, `tear_down_after_script` now runs after its own file's tests instead of alongside them. A resource created by `set_up_before_script` therefore remains available while those tests read it ([#1320](https://github.com/TypedDevs/bashunit/issues/1320)).

The same teardown runs when setup fails, when `--stop-on-failure` halts a sequential run, or when invalid `@timeout` or `@retry` metadata aborts a file. Benchmark files also run their teardown before aborting on a malformed annotation ([#1318](https://github.com/TypedDevs/bashunit/issues/1318), [#1321](https://github.com/TypedDevs/bashunit/issues/1321), [#1322](https://github.com/TypedDevs/bashunit/issues/1322), [#1329](https://github.com/TypedDevs/bashunit/issues/1329)).

## Cleanup after interruption

Ctrl-C reaches the interrupted run's script teardown. In parallel mode, it also reaches the teardown of a test in flight, through the worker that owns those hooks. A second Ctrl-C ends a sequential run even if cleanup does not return ([#1323](https://github.com/TypedDevs/bashunit/issues/1323), [#1331](https://github.com/TypedDevs/bashunit/issues/1331)).

A test killed by `--test-timeout` receives a chance to run `tear_down`. That cleanup is bounded by the watchdog's grace period before it sends SIGKILL, so a hanging hook cannot extend the run indefinitely ([#1324](https://github.com/TypedDevs/bashunit/issues/1324)).

Temporary files created at the top level with `bashunit::temp_file` are also swept when their test file fails to load.

## Parallel errors reach CI

Malformed timeout or retry annotations in a parallel worker now fail the overall run, even when another file passes. Previously the worker printed the error but the parent could still exit zero ([#1335](https://github.com/TypedDevs/bashunit/issues/1335)). This patch makes cleanup and the final verdict reflect what happened inside each file.
