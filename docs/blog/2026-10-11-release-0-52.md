Release 0.52.0 reduces process overhead in data providers and report collection, then tightens the result and cleanup boundaries around parallel tests. Existing quoting, report values and argument behavior are preserved.

## Less work between the tests

Parallel reports collect worker results without starting a base64 process for every row. Data providers likewise pass arguments without a base64 process for each argument, preserving quoted and empty values and keeping the parser isolated ([#1371](https://github.com/TypedDevs/bashunit/issues/1371), [#1370](https://github.com/TypedDevs/bashunit/issues/1370)).

JSON reports avoid a separate process for each ordinary filename, test name or empty message while retaining their escaping rules. Sequential multi-file runs also reuse provider and annotation metadata for unchanged test files up to 512 bytes; the cache is checked against the file's current contents before reuse ([#1369](https://github.com/TypedDevs/bashunit/issues/1369), [#1372](https://github.com/TypedDevs/bashunit/issues/1372)).

## Every provider row keeps its own result

Concurrent provider rows have separate owners for temporary files, including rows with identical arguments. Rows that run synchronously within a parallel run also retain separate results, so a later passing row cannot hide an earlier failure ([#1379](https://github.com/TypedDevs/bashunit/issues/1379), [#1377](https://github.com/TypedDevs/bashunit/issues/1377)).

A late timeout signal no longer interrupts `tear_down`. The watchdog still bounds cleanup that hangs. Piped parallel output can also finish without waiting for an inactive spinner's sleep process ([#1376](https://github.com/TypedDevs/bashunit/issues/1376), [#1368](https://github.com/TypedDevs/bashunit/issues/1368)).

## Shared contributor setup

Repository contributor instructions now come from shared agnostic-ai specs, generated for Claude Code and Codex. The project pins the tool as an npm development dependency and routes task context and model tiers through those sources. Contributors edit `.agnostic-ai/` and regenerate the target files ([#1387](https://github.com/TypedDevs/bashunit/pull/1387)).

Release automation also updates and commits both npm lockfiles' project versions and restores them during rollback. CI compatibility checks scan shell source files without treating generated instructions as executable code, and Linux installer acceptance jobs include their required build optimizer.
