Release 0.44.0 gives custom assertions their own testing and documentation workflow. It also adds explicit snapshot controls and catches configuration mistakes that could previously produce misleading results.

## Build and test custom assertions

`bashunit::assert_that` runs a command and records the assertion verdict in one call. `bashunit::assert_once` lets a composed assertion count and report once under its own label, rather than once for every inner check. Existing assertion totals stay unchanged unless you opt in ([#915](https://github.com/TypedDevs/bashunit/issues/915), [#917](https://github.com/TypedDevs/bashunit/issues/917)).

The new `assert_assertion_passes`, `assert_assertion_fails`, and `assert_assertion_fails_with` helpers test what a custom assertion reports. They isolate its counters and output, so a deliberate failure does not fail the surrounding test ([#916](https://github.com/TypedDevs/bashunit/issues/916)).

```bash
function test_positive_assertion() {
  assert_assertion_passes assert_positive_number 3
  assert_assertion_fails_with "positive number" assert_positive_number 0
}
```

Here, `assert_positive_number` is your project's assertion. Load its bootstrap file to list its documentation alongside the built-in reference, or select only custom assertions with `--custom` ([#918](https://github.com/TypedDevs/bashunit/issues/918)).

```bash
bashunit doc --custom --boot tests/bootstrap.sh
```

## Review snapshots deliberately

Use `--snapshot-update` to re-record existing snapshots after an intentional change, optionally narrowing the run with `--filter`. Snapshots containing placeholders are left alone. In CI, `--no-snapshot-create` makes a missing snapshot fail instead of silently creating the first reference. `--snapshot-report-unused` lists leftovers from renamed or deleted tests without deleting anything, and requires a full run ([#900](https://github.com/TypedDevs/bashunit/issues/900), [#901](https://github.com/TypedDevs/bashunit/issues/901), [#902](https://github.com/TypedDevs/bashunit/issues/902)).

```bash
bashunit tests/ --no-snapshot-create
bashunit tests/ --snapshot-report-unused
```

## Catch mistakes before trusting a pass

Spy assertions now reject an unregistered command instead of treating it as a spy with zero calls. Per-argument comparisons distinguish one argument containing a space from two separate arguments, and failed call checks show the recorded calls.

Invalid options, numeric settings, and missing bootstrap or environment files now produce errors. Coverage also gains an `xtrace` engine on Bash 4.1 and later; automatic selection retains the trap engine on older shells. The supported Bash floor remains 3.0.
