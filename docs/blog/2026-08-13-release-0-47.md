Release 0.47.0 adds structured reports on stdout, reusable suite settings, and controls for individual tests. Coverage now includes tracked files that no test executed, which changes how you should interpret an upgrade's percentages.

## Send reports straight to another command

`--output json` and `--output junit` emit a report on stdout without requiring an intermediate report file. File reporters remain available alongside them ([#1018](https://github.com/TypedDevs/bashunit/issues/1018)).

```bash
bashunit tests/ --output json | jq '.summary'
bashunit tests/ --output junit > report.xml
```

Named `[suite:<name>]` sections in `.bashunitrc` store paths and options. Use `--suite <name>` to select one or repeat the option to combine suites, and `--list-suites` to see available names ([#1021](https://github.com/TypedDevs/bashunit/issues/1021)).

```bash
bashunit --list-suites
bashunit --suite unit
```

## Make test requirements explicit

Per-test `# @timeout`, `# @retry`, and `# @skip` annotations override run-wide settings. Malformed values stop the run instead of quietly falling back. The new conditional skip helpers both mark the test skipped and end it, replacing a separate `return` ([#1020](https://github.com/TypedDevs/bashunit/issues/1020), [#1019](https://github.com/TypedDevs/bashunit/issues/1019)).

`--sandbox` fails a test that invokes an external command it did not mock; `--sandbox-allow` extends the baseline allowlist. For retry-loop tests, `bashunit::mock_sequence` returns successive answers and repeats the final answer when the sequence is exhausted ([#1022](https://github.com/TypedDevs/bashunit/issues/1022), [#1023](https://github.com/TypedDevs/bashunit/issues/1023)).

## Read the corrected coverage denominator

Previously, coverage considered only files a test executed. Now every file under `--coverage-paths` participates, with untouched files reported at zero coverage. Percentages may drop because the measurement includes more of the code. Diff coverage also includes changed files that no test ran, preventing a new untested file from escaping the minimum-percentage check ([#1053](https://github.com/TypedDevs/bashunit/issues/1053), [#1054](https://github.com/TypedDevs/bashunit/issues/1054)).

Corrections to case-arm and function-span parsing also change reported coverage details. Report generation performs its classification and output work in one awk invocation per run rather than repeating shell loops and processes per file.

Benchmark runs gain JSON and JUnit artifacts and median-based baseline comparisons. `--snapshot-prune` removes unused snapshots only after a full run without failures, printing each deleted path; partial runs cannot prune ([#1029](https://github.com/TypedDevs/bashunit/issues/1029), [#1030](https://github.com/TypedDevs/bashunit/issues/1030)).
