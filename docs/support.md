# Support

Ask questions, report bugs, or suggest improvements through [GitHub issues](https://github.com/TypedDevs/bashunit/issues).

Search existing issues first. If you open a new one, include:

- The bashunit version, Bash version, and operating system.
- Steps to reproduce the problem, with a small test case if possible.
- The expected result, actual output, and any error messages.

Keep discussions respectful and constructive.
